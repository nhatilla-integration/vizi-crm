# Vizi CRM — contexto do projeto

O Vizi CRM é um **produto da Natilla**, não pertence e não está vinculado a nenhum
cliente específico. Ele deve estar pronto para ser usado por qualquer
microempresa que atenda via WhatsApp e venda produto, serviço, ou os dois.

**Fernando** (loja PC Camp) foi cogitado como o primeiro comércio a testar o
sistema, mas **não seguiu adiante**. Trate isso como um episódio encerrado do
histórico do projeto — não como uma integração ativa, uma dependência atual,
nem como "o cliente do Vizi". Não assuma que ele vai usar o sistema, não
construa funcionalidades pensando só no caso dele, e não trate o Supabase
hoje conectado (que ainda tem a conta de teste dele) como permanente — é
provável que seja substituído por um projeto Supabase novo e genérico quando
houver um usuário real de verdade.
